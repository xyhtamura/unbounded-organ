# Asset provenance

The instrument ships no images, icons, audio samples, or font files. Its pages
request three typefaces from Google Fonts at runtime and fall back to local
system faces when that request is unavailable.

| Asset | Source | License | Checked |
|---|---|---|---|
| Alegreya | [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/alegreya) | SIL Open Font License 1.1 | 2026-09-02 |
| Alegreya Sans | [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/alegreyasans) | SIL Open Font License 1.1 | 2026-09-02 |
| IBM Plex Mono | [IBM Plex repository](https://github.com/IBM/plex) | SIL Open Font License 1.1 | 2026-09-02 |

The archived bamboo-organ façade in `reference/bamboo-organ-facade.html` is
drawn entirely in project-authored HTML and CSS. Its structural reference is
the [Bamboo Organ Foundation](https://bamboo-organ.com/) page; no image or
ornament from that page is copied or redistributed.
